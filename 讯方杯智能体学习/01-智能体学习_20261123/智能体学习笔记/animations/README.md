# 动画工程说明

> 全部 19 段知识点动画，**来自这一个 Remotion 工程**。
> 不新建工程、不重复写组件 —— 改数据就行。

---

## 为什么只有一个工程

所有动画共用**一个模板组件** `src/Scene.tsx`，它接受一个 `Scene` 对象渲染。
19 段动画只是 `src/scenes.ts` 里 19 个数据条目。

```text
src/
├── index.ts         入口（registerRoot）
├── Root.tsx         循环数组，把每条数据注册成一个 composition
├── Scene.tsx        ★ 唯一模板组件：3 个分镜 + 背景 + 动效
└── scenes.ts        ★ 数据表：19 个知识点，改这里就够
```

**新增一个知识点** = 在 `scenes.ts` 里加一个对象，重跑渲染。不用碰任何组件代码。

---

## 每段动画的结构

每段 24 秒，**三个分镜依次切换**，右上角有 1/2/3 指示条：

| 分镜 | 时长 | 内容 | 视觉 |
|---|---|---|---|
| ① **立论** | 8s | 一句话核心观点（大字） | 超大标题 + 旋转圆环 + 标签 |
| ② **展开** | 8s | 卡片 / 对比表 / 补充说明 | 3-6 张卡片或 4 行对比表，逐张弹入 |
| ③ **落地** | 8s | 编号要点 + 横向流程条 | 要点逐条上浮，流程条点亮 |

细节动效：字节跳动式文字揭示、卡片弹入、逐条揭示、进度条、光球漂移、扫描光带、分镜指示器。

## 常用命令

```powershell
cd animations

npm install          # 首次
npm run render       # 渲染所有「还没有」的
npm run render -- --force   # 全部重渲
npm run studio       # 打开可视化编辑器实时预览
```

> 渲染结果直接输出到 `../动画/`，Obsidian 里 `![[名字.mp4]]` 立刻能播。

## 改一个动画的流程

1. 打开 `src/scenes.ts`，找到对应条目
2. 改 `pitch.big`（立论大字）、`explain`（展开内容）、`apply`（落地要点）
3. 删掉 `../动画/对应名字.mp4`
4. `npm run render`

**只有 4 个字段决定内容**，不需要懂 React。

## 关于配音

**每段动画都有中文旁白**，音色 `zh-CN-XiaoyiNeural`（晓伊），语速 +18%。

### 配音怎么对齐画面对

关键点：**旁白按分镜切分，不是整段念**。

```text
分镜1（8s）  分镜2（8s）  分镜3（8s）
   ↓            ↓            ↓
 三句话分别合成 → 各自补齐/压缩到精确 8 秒 → 拼接成 24 秒
```

所以语音和画面**永远同步**，不会出现"讲到第三页画面还在第一页"。

### 重新生成配音

```powershell
cd animations
python make_voice.py                    # 全部重配
python make_voice.py 04-Agent工作流       # 只重配某一段
```

脚本 `make_voice.py` 里顶部的 `SCRIPT` 字典就是**全部旁白文案**，改文字即可。

> 如果某句太长被自动加速，脚本会在输出里提示 `超长 → 加速至 8s`。
> 建议每句控制在 **45 字以内**，听起来最自然。

### 依赖

- `edge-tts`（免费，微软神经网络语音）
- `ffmpeg`（本机已有）

## 关于语音和音效

**有中文旁白，无背景音乐。**

如果要加背景音乐，把音频放到 `public/bgm.mp3`，并在渲染时设环境变量 `REMOTION_BGM=1`。
