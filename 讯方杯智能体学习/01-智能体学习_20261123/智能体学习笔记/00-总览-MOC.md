## 🔗 跨章节的核心线索

这些概念在多个章节反复出现，把它们连起来才是真的懂了。

### 线索一：**「示例」的三种用法**

- [[02-提示词基础]] 的**技巧4**：给一两个例子，让它照着格式写 —— 这是最朴素的用法
- [[03-提示词进阶]] 的**少样本学习**：把「给例子」系统化成 2-5 个高质量样例
- [[03-提示词进阶]] 的**上下文学习**：极端版 —— 直接丢一大段材料进去让它归纳

> 同一条线：**从「举例」到「喂数据」**。

### 线索二：**「记忆」是怎么一步步加上的**

- [[01-大模型基础]]：模型本身是**无状态**的，每次对话都是新的
- [[02-提示词基础]]：靠**角色设定**假装它有身份
- [[04-Agent基本原理]]：**基于模型的 Agent** 首次引入状态记忆
- [[05-Agent开发入门]]：**知识库** 是外挂记忆，**对话历史** 是短期记忆
- [[06-多智能体系统]]：**共享知识库** 成了团队记忆

> 同一条线：**从无记忆到外挂记忆，再到共享记忆**。

### 线索三：**复杂度递增的五级台阶**

[[04-Agent基本原理]] 里的五级智能，正好对应课程的进阶路径：

| 层级 | 智能体类型 | 在课程里对应什么 |
|---|---|---|
| L1 | 反应式 | [[02-提示词基础]] 的固定模板 |
| L2 | 基于模型 | 带对话记忆的 Agent（[[05-Agent开发入门]]） |
| L3 | 基于目标 | 工作流编排（[[05-Agent开发入门]]） |
| L4 | 基于效用 | 多目标权衡（[[07-生态与工具链]]） |
| L5 | 基于学习 | 反馈优化（[[08-瓶颈与展望]] 的自适应） |

## 🎯 三张速查表

### 提示词选型（来自 [[03-提示词进阶]]）

| 策略 | 何时用 | 典型场景 |
|---|---|---|
| 零样本 | 简单任务、快速试水 | 情感判断 |
| 少样本 | 格式固定、专业输出 | 信息抽取、法律条款 |
| 思维链 | 需要推理、多步计算 | 商业决策、数学 |
| 上下文学习 | 有大量素材、规则要迁移 | 报表分析 |

### Agent 五级智能（来自 [[04-Agent基本原理]]）

| 层级 | 特点 | 典型场景 |
|---|---|---|
| 反应式 | 刺激→反应，无记忆 | 智能灯具 |
| 基于模型 | 记状态、能预测 | 导航、棋类 |
| 基于目标 | 围绕目标搜索最优解 | 物流调度 |
| 基于效用 | 多目标权衡 | 自动驾驶 |
| 基于学习 | 数据驱动自我进化 | 推荐、AlphaGo |

### 能力扩展四路线（来自 [[07-生态与工具链]]）

```text
提示词 ──► +知识库 ──► +插件 ──► +API/工作流
 最轻        懂私事       有手脚       能编排
```
