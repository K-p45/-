# 第1章 · 大模型概述与产业全景

> **一句话**：大模型不是「更大的模型」，而是**能力会跨过临界点突然涌现**、**性能可以按算力预测**的一类新事物。

## 🎬 核心概念

![[101-涌现与缩放定律.mp4]]

### 定义

大语言模型（LLM）= **参数规模数十亿以上**的深度神经网络，通过阅读海量文本学习语言规律。

核心是 **Transformer 架构**（2017，Google）。

### 专才 vs 通才（关键区别）

| | 传统 AI | 大模型 |
|---|---|---|
| 定位 | **专才** | **通才** |
| 一个模型做几件事 | 一件 | 所有语言任务 |
| 换任务怎么办 | 重新收集数据、**重新训练** | 换**提示词**就行 |
| 例子 | 垃圾邮件分类器 | GPT-4 / DeepSeek |

> 💡 **这才是本质差别**：传统 AI 是「一模型一任务」，大模型是「一模型，靠提示词适配 N 个任务」。**成本结构彻底变了。**

---

## 📈 两个最重要的理论

### 1. 涌现能力（Emergent Abilities）

> 参数少的时候，某些复杂任务**几乎完全不会**；
> 参数跨过某个临界点后，能力**突然冒出来**。

课程里的类比很贴切：**水加热到 100°C 突然沸腾 —— 变化不是线性的。**

> 💡 **为什么这事重要**：如果能力是线性增长，那大模型不过是"好一点的工具"。涌现在意味着**存在一个门槛，跨过去就是另一个物种**。这也是各家公司拼命堆参数的根本原因。

### 2. 缩放定律（Scaling Law）

> 模型性能可以用**参数量、数据量、计算量**三个因素预测。
> 三者同步扩大时，性能**平稳可预测地**提升。

**做菜类比**：食材（数据）、厨具（算力）、食谱复杂度（参数）三者必须匹配，只加大一项很快遇到瓶颈。

| 模型 | 参数量 | 训练成本 |
|---|---|---|
| GPT-3 | 1750 亿 | 约 460 万美元 |
| DeepSeek-V3 | 6710 亿（MoE） | 约 557 万美元 |

> 🎯 **注意这个反常现象**：DeepSeek-V3 参数是 GPT-3 的近 4 倍，成本却只多 20%。
> 这说明**架构优化（MoE）能让缩放曲线整体上移** —— 用更少算力训练更大模型。这就是「效率即竞争力」的由来。

## 🗂️ 模型分类

### 按模态

| 类型 | 能力 | 代表 |
|---|---|---|
| 纯文本 | 只处理文字 | GPT-4-turbo、DeepSeek-V3 |
| 多模态（输入） | 能看图 + 读字 | GPT-4o、Qwen-VL |
| 生成式多模态 | 还能出图/音/视频 | Sora、Gemini |

### 按开放程度（选型关键）

| | 闭源 | 开源 |
|---|---|---|
| 代表 | GPT-4、Claude、Gemini | LLaMA、Qwen、DeepSeek、ChatGLM |
| 优点 | 性能领先、开箱即用 | **可私有化、可微调** |
| 缺点 | **数据隐私不可控**、价格由人定 | 需要自己部署调优 |
| 适合 | 快速验证、非敏感场景 | **数据敏感行业** |

## 🧬 技术发展脉络

```text
规则时代 → 统计时代 → 深度学习 → 预训练时代
                                    ↓
              2013 Word2Vec      词有了向量
              2017 Transformer   注意力取代循环
              2018 BERT / GPT    双向理解 vs 单向生成
              2020 GPT-3         少样本学习涌现
              2022.11 ChatGPT    对齐后走向大众
              2023-              GPT-4 · 国产百模大战
```

### 三个关键节点

**① 2018：两条路线的分叉**

- **BERT**（Google）：双向编码，擅长**理解**
- **GPT**（OpenAI）：从左到右预测下一个词，擅长**生成**

> 💡 这个分叉决定了今天所有模型的形态。**生成模型必须因果**（写第 5 个词不能偷看第 6 个），所以 GPT 系只能单向；BERT 系双向但不会生成。

**② 2022.11.30：ChatGPT 的引爆**

关键不是模型更强，而是 **RLHF 对齐**让「能说」变成了「说得好」。

| | 时间 |
|---|---|
| 百万用户 | **5 天** |
| 1 亿月活 | **2 个月** |
| 对比 TikTok | 9 个月 |

**③ 2023-2025：国产崛起**

- **DeepSeek**：用极小成本做出 GPT-4 级别，开源标杆
- **通义千问**：从 0.5B 到 72B 完整尺寸矩阵
- **文心一言**：整合百度搜索生态
- **Kimi**：200 万字长文本

## 🇨🇳 国产生态与关键洞察

### DeepSeek 为什么轰动

| 版本 | 时间 | 关键技术 |
|---|---|---|
| V2 | 2024.5 | **MLA**：KV Cache 压缩 93.3% |
| V3 | 2024.12 | 671B 参数，256 专家，**每次只激活 37B** |
| R1 | 2025.1 | **GRPO**：纯强化学习训出推理能力，追平 o1 |

> 🎯 **一句话看懂 DeepSeek 的路子**：不跟别人比谁参数多，而是比**「同样效果下，谁用的算力少」**。
> MLA 省显存、MoE 省计算、GRPO 省标注数据 —— 三招全打在成本上。

### 硬件这一环

**华为昇腾 910B** ≈ A100 的 80-90%，是国内最成熟的替代方案。
配套 **MindSpore**（框架）+ **MindIE**（推理引擎）。

### 工具链

| 工具 | 定位 |
|---|---|
| **Dify** | 可视化工作流 + RAG，60K+ Star |
| **FastGPT** | 专注知识库问答 |
| **LangChain** | 代码框架，生态最全 |

## 💰 商业化：三种模式

![[102-三种商业模式.mp4]]

| 模式 | 怎么赚钱 | 谁在用 |
|---|---|---|
| **API 服务** | 按 token 计费 | OpenAI、DeepSeek |
| **行业方案** | 端到端交付 | 华为盘古、微软 Azure |
| **开源生态** | 社区版免费 + 企业版收费 | Meta LLaMA、Mistral |

### API 成本对比（这个差距很夸张）

| 模型 | 输入（/百万 token） |
|---|---|
| GPT-4o | 约 **2.5 美元** |
| DeepSeek-V3 | 约 **1 元人民币** |

> 💡 **差了将近 20 倍**。所以国内做应用，DeepSeek 这类模型是首选。
> 一个日活 1 万用户的客服系统，月成本约 3000-5000 元 —— **很多场景根本不需要私有化部署**。

### 选型建议

```text
初创 / 快速验证  →  API（低门槛、按量付费）
数据敏感行业     →  私有化部署（合规、可控）
技术团队强       →  开源自建（灵活、成本低）

实际最佳实践：先用 API 验证，跑通了再私有化
```

## 🏭 行业落地速查

![[103-行业落地案例.mp4]]

| 行业 | 用法 | 效果 |
|---|---|---|
| **金融** | 风控文本分析、智能客服 | 一次性解决率 65% → 85% |
| **医疗** | 影像筛查、病历质控 | 阅片 15 分钟 → 3 分钟 |
| **法律** | 合同审查 | 单份审查 2-4 小时 → 分钟级 |
| **制造** | 视觉质检、设备运维 | 漏检率 3% → 0.5% |
| **电商** | 商品标题、营销文案 | 点击率 +10~15% |
| **政务** | 政策解读、办事指引 | —— |
| **研发** | 代码补全 | 编码速度 +55% |

> 🎯 **看这张表的共同点**：全部是**「AI 辅助 + 人工审核」**，没有一个是全自动。
> 医疗尤其明显 —— 模型帮医生筛病灶，但**诊断责任仍在医生**。

## ⚠️ 落地的三个坎

### 坎一：幻觉

模型会**非常自信地说错话** —— 编造论文引用、虚构法条、算错数。

**三层防御**：

| 层 | 手段 | 作用 |
|---|---|---|
| 1 | **RAG** 检索增强 | 提高基准准确率 |
| 2 | **模型自检** | 置信度低于阈值就拦截 |
| 3 | **人工审核** | 最终把关 |

### 坎二：数据安全与合规

- 敏感数据不能出内网 → 私有化部署
- 需要审计追溯 → 日志全留

### 坎三：成本控制

**核心策略：小模型优先。**

| 方案 | 准确率 | 成本 |
|---|---|---|
| GPT-4 | 95% | 10 美元/百万 token |
| DeepSeek-V3 | 93% | 1/10 |
| 微调 7B 本地跑 | 91% | **接近 0** |

> 🎯 **2% 的准确率差异，用户根本感知不到，但成本差一个数量级。**
> 「必须用最强模型」是很多人踩的坑。

2. 涌现能力为什么让各家拼命堆参数？
3. DeepSeek-V3 参数比 GPT-3 多 4 倍，为什么成本只多 20%？
4. 什么情况下应该选开源模型而不是 API？
5. 为什么说"必须用最强模型"是个坑？

<details>
<summary>参考答案</summary>

1. 传统 AI 是专才，一模型一任务，换任务要重训；大模型是通才，一个模型靠提示词适配所有任务。
2. 涌现意味着存在能力临界点，跨过去就是质变，所以堆参数能换来非线性回报。
3. 因为采用 MoE 稀疏架构，671B 参数每次只激活 37B，实际计算量远小于稠密模型。
4. 数据敏感（不能出内网）、需要深度定制、调用量巨大导致 API 成本过高时。
5. 因为小模型往往只差 2% 准确率，用户感知不到，但成本可能低一个数量级。
</details>
