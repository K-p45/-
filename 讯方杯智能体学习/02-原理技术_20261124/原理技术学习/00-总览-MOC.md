## 🔗 贯穿全课的四条主线

这几条线反复出现，把它们串起来才是真懂了。

### 线索一：**「效率」才是主旋律**

```text
第1章  DeepSeek 参数多 4 倍，成本只多 20%   → 架构优化
第3章  MoE：总参数 671B，只激活 37B         → 稀疏化
第3章  MLA：KV Cache 压缩 93.3%             → 省显存
第4章  量化/蒸馏/LoRA：各种压缩手段           → 系统化
第5章  模型越做越小（端侧 1B-7B）            → 趋势
```

> 🎯 **整个行业的竞争焦点，不是"谁更强"，而是"同样效果下谁更便宜"。**
> 这条线从第 1 章贯穿到第 8 章。

### 线索二：**「从静态到动态」**

| 阶段 | 静态 → 动态 |
|---|---|
| 词向量 | One-hot（死）→ Word2Vec（固定）→ **ELMo/BERT（随上下文变）** |
| 检索 | 关键词匹配（字面）→ **语义检索（意思）** |
| 模型 | 专才（一任务一模型）→ **通才（提示词适配）** |
| 使用 | 手动写每一步 → **Agent 自主规划** |

### 线索三：**「成本 vs 效果」的三个权衡**

| 场景 | 左边 | 右边 | 怎么选 |
|---|---|---|---|
| 微调 | 全参数（贵、全能力） | **LoRA（省 95%）** | 通用全参，垂直 LoRA |
| 量化 | INT8（准） | **INT4（省 8 倍）** | 够显存 INT8，消费级 INT4 |
| 检索 | 纯向量（快但粗） | **混合 + Rerank（准但慢）** | 先粗筛 20 再精排 3 |

### 线索四：**「幻觉」的三道防线**

```text
第7章  RAG          → 提高基准准确率（有据可依）
第6章  负向约束      → "不确定就说不知道"
第1章  人工审核      → 最终把关
```

> 三层组合使用才是生产级方案（第 1 章讲过）。

## 🎯 三张速查表

### Transformer 必背（第3章）

| 要素 | 要点 |
|---|---|
| Q/K/V | Q 查 K 得权重，加权求和 V |
| √d_k | 防内积过大导致 softmax 梯度消失 |
| Mask | softmax 前置 -∞，实现自回归 |
| 交叉注意力 | Q 来自 Decoder，K/V 来自 Encoder |

### 微调决策树（第4章）

```text
数据量大 + GPU 充足？ → 全参数微调
数据量小 + GPU 有限？ → LoRA（参数省 95%）
只有一张 4090？       → QLoRA（量化 + LoRA）
```

### RAG 决策树（第7章）

```text
"基于文档回答" → RAG
"学风格/技能"  → 微调
两者都要       → RAG + 微调

分块：200-500 字，重叠 50-100
检索：混合检索（关键词 + 语义）+ RRF
精排：Top-20 → Rerank → Top-3
```
