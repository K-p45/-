# 第5章 · 多模态大模型

> **一句话**：多模态的核心问题是**「怎么把图片和文字放进同一个空间」**。
> CLIP 用对比学习回答了它 —— 这也是今天所有文生图、图生文的基础。

## 🎬 一、多模态是什么

![[501-多模态四种架构.mp4]]

### 定义

**多模态学习**：让模型同时处理**文本、图像、音频、视频**等多种信息。

### 四个主要任务

| 任务 | 做什么 | 例子 |
|---|---|---|
| **多模态传译** | 模态间转换 | 看图说话（图像描述） |
| **多模态对齐** | 找到模态间的对应 | 注意力机制定位"猫"在哪 |
| **多模态分类** | 联合判断 | 视频情感分析 |
| **多模态联合学习** | 共同训练 | 图文匹配 |

### 三个概念的区分（容易混）

| 概念 | 含义 |
|---|---|
| **单模态** | 只用一种输入（纯文本模型） |
| **多模态** | 能处理多种输入（GPT-4V） |
| **跨模态** | 从一种模态**迁移到**另一种（文字→图片） |

## 🖼️ 二、四代架构演进

![[11-多模态大模型技术理论/幻灯片13.PNG]]

从历史看，多模态经历了：**行为时代 → 计算时代 → 交互时代 → 深度学习时代 → 大模型时代**。

今天主流是四种架构：

### ① 融合编码器架构（ViLBERT）

```text
图片 → 图像编码器 ┐
                  ├→ 融合层（交叉注意力）→ 输出
文本 → 文本编码器 ┘
```

**特点**：两种模态在**同一层里交互**。
**缺点**：融合计算量大。

### ② 双塔对比学习架构（CLIP）⭐

```text
图片 → 图像编码器 → 图像向量 ┐
                              ├→ 对比学习对齐
文本 → 文本编码器 → 文本向量 ┘
```

**特点**：**两个塔分开编码，最后比相似度**。
**优势**：可以**预先算好**所有图片的向量，检索极快。

> 🎯 **CLIP 是本章最重要的模型**，后面单独讲。

### ③ 编码解码 + LLM 桥梁架构（BLIP-2）

```text
图片 → 图像编码器 → [Q-Former 桥梁] → 大语言模型 → 文本
```

**特点**：用一个小模块把**视觉特征翻译成语言模型能懂的形式**。
**优势**：可以借助**现成的强大 LLM**，训练成本低。

### ④ 大一统生成式架构（GPT-4V / GPT-4o）

```text
图片 + 文本 → 统一表示 → 统一生成
```

**特点**：**原生多模态**，所有模态进同一个模型，输出也可以是任意模态。

> 💡 **演进方向很清楚**：从「拼接两个独立模型」→「加个桥梁」→「天生就是一个模型」。

## 🎯 三、CLIP：对比学习范式

### 核心思想

> **不直接学「图是什么」，而是学「哪张图和哪段文字是一对」。**

### 怎么训练

```text
一个 batch 取 N 对（图片, 文字）：

  [图1]  [图2]  [图3]  ...  [图N]
    ↓      ↓      ↓            ↓
  图像向量（N 个）
    ↕     ↕      ↕            ↕   ← 算 N×N 相似度矩阵
  文本向量（N 个）
    ↑      ↑      ↑            ↑
  [文1]  [文2]  [文3]  ...  [文N]

目标：对角线（配对）相似度 → 最大化
      非对角线（不配对）   → 最小化
```

**材料**：4 亿对（图, 文）—— 直接从网上爬，**不需要人工标注**。

> 🎯 **这就是 CLIP 能规模化训练的原因**：互联网上「图片 + alt 文字」天然成对，标注成本为零。

### 学完之后能干什么

| 能力 | 原理 |
|---|---|
| **零样本分类** | 给每类写个描述，算图片和哪个描述向量最像 |
| **图片检索** | 文字搜图 |
| **文生图的底座** | Stable Diffusion 就用 CLIP 做文本编码 |

> 💡 **零样本分类是 CLIP 最惊人的能力**：没训练过的类别，只要你说出名字，它就能认出来。
> 因为它学的不是「类别」，而是「图文对应关系」。

## 🔬 四、技术原理：特征提取与融合

### 文本特征提取

```text
文本 → token 化（jieba 等分词 / 预训练模型 tokenizer）→ 词汇序列 → 向量
```

### 图像特征提取

```text
图像 → 调整尺寸 → 张量化 → CNN → 特征图 → 扁平化 → 特征向量
```

> **CNN 的优势**：端到端，几乎不用预处理。

### 多模态融合：两个层次

![[11-多模态大模型技术理论/幻灯片33.PNG]]

### ① 特征级融合（早期融合）

```text
向量 a = (a₁...aₙ)
向量 b = (b₁...bₘ)

线性组合：f = α·a + β·b
```

- **α、β** 是权重，可按模态重要性设置，也可以**用注意力机制学出来**
- 当 α=β=0.5 时，就是取平均

**优点**：信息保留最完整
**缺点**：要求两个向量**长度相等**，且对模态缺失敏感

### ② 决策级融合（晚期融合）

```text
图片 → 分类器1 → 结果1 ┐
                       ├→ 投票 / 取最大 / 加权 → 最终结果
文本 → 分类器2 → 结果2 ┘
```

**关键优势**（这个很重要）：
> **某个模态缺失时，其他模态还能继续工作。**

> 🎯 **特征级 vs 决策级怎么选**：
> - 两个模态都很重要且都在 → **特征级**（信息更全）
> - 可能缺模态、或模态差异极大 → **决策级**（更鲁棒）

### 基于模型的融合 vs 模型无关的融合

| 类型 | 含义 | 例子 |
|---|---|---|
| **基于模型** | 融合方式和任务、结构绑定 | 视觉问答、多模态对话 |
| **模型无关** | 通用，不依赖特定网络 | 特征级/决策级融合 |

| 单/多/跨模态 | 一种 / 多种 / 从一种迁到另一种 |

## ❓ 自测

1. 单模态、多模态、跨模态分别是什么？
2. CLIP 的训练目标是什么？
3. CLIP 为什么能做零样本分类？
4. 特征级融合和决策级融合的关键区别？
5. BLIP-2 为什么需要"桥梁"？

<details>
<summary>参考答案</summary>

1. 单模态只用一种输入；多模态能处理多种输入；跨模态指从一种模态迁移到另一种。
2. 在同一 batch 里，让配对的图文向量相似度最大化，不配对的最小化。
3. 它学的是图文对应关系而非固定类别，所以给出任意类别的文字描述就能判断图片最像哪个。
4. 特征级在特征层面直接融合（信息全但对模态缺失敏感）；决策级在各自输出上融合（某个模态缺失时其他还能工作）。
5. 图像编码器输出的视觉特征和语言模型的输入空间不匹配，需要一个模块做"翻译"。
</details>
