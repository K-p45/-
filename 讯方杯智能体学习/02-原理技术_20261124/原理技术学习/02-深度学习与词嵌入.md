## 🎬 一、深度学习基础

![[201-深度学习与CNN.mp4]]

### 深度学习在 AI 里的位置

```text
人工智能 ⊃ 机器学习 ⊃ 深度学习
```

**机器学习** = 用已有数据（经验），得出模型（规律），再预测未来。

### 「深度」到底深在哪

这个词有三层含义，很多人只理解第一层：

| 层 | 含义 | 代价 |
|---|---|---|
| **大算力** | 层深 → 参数多 → 需要大量计算 | GPU 的进步才让它成为现实 |
| **大数据** | 参数多 → 需要海量数据喂养 | 否则训不动这么参数 |
| **梯度消失/爆炸** | 反向传播时梯度逐层衰减或放大 | 网络太深就训不收敛 |

> 💡 **第三点最容易被忽略**：为什么以前做不了深层网络？不只是算力不够，而是**梯度传到底层时已经趋近于零，底层参数根本得不到更新**。残差连接（ResNet）就是为解决这个而生的 —— 这也会在 Transformer 里再次出现。

### 四种基础网络

| 网络 | 全称 | 擅长 | 今天还在用吗 |
|---|---|---|---|
| **FCNN** | 全连接神经网络 | 数值拟合、分类 | 作为末端分类器 |
| **CNN** | 卷积神经网络 | **图像**特征提取 | ✅ 大量使用 |
| **RNN** | 循环神经网络 | **序列**（早期文本） | ❌ 被 Transformer 取代 |
| **Attention** | 注意力机制网络 | 一切 | ✅ **今天的主流** |

> 🎯 **这张表就是一部简史**：CNN 管图像，RNN 管文本，然后注意力把两者都统一了。

### CNN 为什么强

![[03-深度学习基础/幻灯片29.PNG]]

**灵感来自人眼**：视觉神经元只对视野中一小块区域敏感（感受野）。

**卷积层**：一个卷积核在图像上滑动，每次只看一个局部，做**加权求和**。

```text
输入图像  →  [卷积核滑动]  →  特征图
            每一格 = 覆盖区域像素 × 权重，求和
```

**三个核心组件**：

| 组件 | 作用 | 一句话 |
|---|---|---|
| **卷积层** | 特征提取 | 滑窗加权求和，找边缘/纹理/形状 |
| **池化层** | 特征压缩 | 降维、抗位移（最大池化取最大，平均池化取均值） |
| **全连接层** | 整合判决 | 把特征映射到标签 |

> 💡 **CNN 的两个天然优势**：
> - **局部连接** —— 每个神经元只看一小块，参数少
> - **权值共享** —— 同一个卷积核扫全图，参数复用
>
> 这让 CNN 的参数效率远超全连接网络。**同理，Transformer 的注意力也是在做"参数共享"** —— 只是共享方式不同。

### 传统方法 vs 深度学习

| | 传统机器视觉 | 深度学习 |
|---|---|---|
| 特征怎么来 | **人工设计**（边缘、纹理、SIFT） | **自动学习** |
| 泛化能力 | 差，换个场景就崩 | 强 |
| 可解释性 | 好 | 差 |
| 适合 | 规则固定、光照稳定的场景 | 复杂、多变的真实场景 |

> 工业质检的例子很典型：漏检率从 3% 降到 0.5%。

## 🎬 二、词嵌入：从 One-hot 到 BERT

![[202-词向量演进.mp4]]

这是本章的核心。**五个模型，一条进化线**：

```text
One-hot  →  Word2Vec  →  GloVe  →  ELMo  →  BERT
稀疏高维    密集语义     全局统计   上下文动态  双向预训练
(2013)                 (2014)    (2018)    (2018)
```

### 1️⃣ One-hot：最简单，也最没用

**做法**：词汇表多大，向量就多长。词在哪个位置，哪里就是 1。

```text
词汇表 = {apple, banana, grape}

apple  → [1, 0, 0]
banana → [0, 1, 0]
grape  → [0, 0, 1]
```

**三个致命问题**：

| 问题 | 说明 |
|---|---|
| **维度爆炸** | 10 万词表 = 10 万维向量 |
| **稀疏** | 除了一个 1，全是 0，极度浪费 |
| **无相似性** | 任意两个词的距离都相等 —— **apple 和 banana 的关系 = apple 和 grape 的关系** |

> 🎯 **第三点是致命的**：One-hot 表达不出「猫和狗很像」这件事。而语言的本质就是关系。

### 2️⃣ Word2Vec：革命性的起点（2013，Google）

**核心思想**：**用上下文定义词**。

> 「观其伴，知其义」—— 一个词的含义，由它经常一起出现的词决定。

**两个训练方式（考试常考）**：

| 模型 | 输入 → 输出 | 记忆 |
|---|---|---|
| **CBOW** | 上下文 → 当前词 | 用周围的词猜中间 |
| **Skip-gram** | 当前词 → 上下文 | 用中间的词猜周围 |

```text
CBOW:      "我 [爱] 机器"    ← 给"我""机器"，猜"爱"
Skip-gram: "我 [爱] 机器"    → 给"爱"，猜"我""机器"
```

**最著名的证据**：

```text
国王 - 男人 + 女人 = 女王
```

> 💡 这说明词向量不只是「编码」，而是**真的捕捉到了语义结构**。向量空间里，性别这个维度是可以被加减的。

**局限**：一个词只有一个固定向量 → **无法处理一词多义**。

### 3️⃣ GloVe：看全局（2014，斯坦福）

**和 Word2Vec 的区别**：

| | Word2Vec | GloVe |
|---|---|---|
| 看什么 | **局部**窗口（前后几个词） | **全局**共现统计 |
| 方法 | 神经网络训练 | 对共现矩阵做**矩阵分解** |

> 💡 GloVe 想解决的是「Word2Vec 只看邻居，看不到整个语料库的统计规律」这个问题。

### 4️⃣ ELMo：第一个「会看上下文」的

**关键突破**：**同一个词，在不同句子里有不同向量**。

```text
"苹果很好吃"   → 苹果 = [0.2, 0.8, ...]   （水果）
"苹果发布新机" → 苹果 = [0.9, 0.1, ...]   （公司）
```

**怎么做到的**：用**深度双向** LSTM 语言模型，把整句话的语境编码进词向量。

> 🎯 **这是真正的分水岭**。之前所有模型都是「静态词向量」—— 查询表，查出来的永远一样。ELMo 开始，词向量是**根据上下文实时算出来的**。

### 5️⃣ BERT：站在 Transformer 上（2018，Google）

**两个创新**：

| 创新 | 做法 | 意义 |
|---|---|---|
| **双向** | 同时看左右两边 | 比 ELMo 的双向拼接更彻底 |
| **Transformer 编码器** | 用注意力代替 LSTM | 可并行、更强 |

**预训练任务**：

- **MLM（掩码语言模型）**：随机遮住 15% 的词，让模型猜
- **NSP（下一句预测）**：判断两句是不是连续的

> 💡 **为什么 MLM 这么重要**：它逼模型**同时利用左右两边**的上下文来填空。这就是 BERT 能「双向理解」的根本原因 —— 不是架构上做了双向，而是**任务设计逼出来的**。

### 演进总结

![[04-词嵌入技术理论/幻灯片11.PNG]]

| 模型 | 解决什么问题 | 留下的问题 |
|---|---|---|
| One-hot | 能表示词了 | 稀疏、无相似性 |
| Word2Vec | 有了**语义相似性** | 一词一向量 |
| GloVe | 补上**全局统计** | 一词一向量 |
| ELMo | **上下文动态** | 双向不彻底、慢 |
| BERT | **彻底双向 + 并行** | 只能理解，不能生成 |

> 🎯 **最后这一行是关键**：BERT 很强，但**它不会生成**。真正能写文章、能对话的，是另一条路线 —— GPT。这就是下一章 Transformer 要讲的。

## 💻 代码速查

### One-hot

```python
import numpy as np

text = "apple banana apple grape"
words = text.split()
vocab = sorted(set(words))                     # ['apple','banana','grape']
word_to_index = {w: i for i, w in enumerate(vocab)}

def one_hot_encode(word):
    v = np.zeros(len(word_to_index))
    v[word_to_index[word]] = 1
    return v
```

### Word2Vec（gensim）

```python
from gensim.models import KeyedVectors
model = KeyedVectors.load_word2vec_format('GoogleNews-vectors-negative300.bin', binary=True)
vec = model['apple']          # 300 维密集向量
model.most_similar('king')    # 找相似的词
```

### GloVe

```python
import numpy as np
def load_glove(path):
    model = {}
    for line in open(path, encoding='utf-8'):
        parts = line.split()
        model[parts[0]] = np.array([float(x) for x in parts[1:]])
    return model

glove = load_glove('glove.6B.50d.txt')   # 50 维
```

### BERT（Hugging Face）

```python
from transformers import BertTokenizer, BertModel
import torch

tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

inputs = tokenizer("The capital of France is Paris", return_tensors="pt")
with torch.no_grad():
    out = model(**inputs)

hidden = out.last_hidden_state    # [batch, seq_len, 768]
# 取某个词的向量：先找它在 input_ids 里的位置
```

1. 深度学习的「深度」有哪三层含义？
2. One-hot 编码最致命的问题是什么？
3. CBOW 和 Skip-gram 分别是什么？
4. ELMo 相比 Word2Vec 的关键突破是什么？
5. BERT 的双向理解是怎么实现的？
6. BERT 这么强，为什么还需要 GPT？

<details>
<summary>参考答案</summary>

1. 大算力、大数据、梯度消失/爆炸（训练困难）。
2. 任意两个词的向量距离都相等，无法表达词与词之间的语义相似性。
3. CBOW 用上下文预测当前词；Skip-gram 用当前词预测上下文。
4. 词向量从静态变成动态——同一个词在不同语境下有不同的向量表示。
5. 通过 MLM 掩码语言模型任务：随机遮住部分词，逼迫模型同时利用左右两侧的上下文来预测。
6. BERT 是双向编码器，只能做理解任务（分类、抽取），无法自回归生成；生成需要 GPT 这种单向解码器。
</details>
