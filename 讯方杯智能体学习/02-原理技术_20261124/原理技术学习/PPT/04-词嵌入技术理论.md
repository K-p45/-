## 第 6 页

- 一、词向量简介
- 词向量技术的应用极为广泛，几乎涵盖了自然语言处理的所有领域，从基础的词性标注、命名实体识别到复杂的机器翻译、情感分析等任务，词向量都发挥着不可或缺的作用。通过预训练的词向量，模型可以更快地收敛，同时提高最终任务的准确率。

![[词嵌入技术理论/幻灯片6.PNG]]

## 第 7 页

- 二、词向量的技术演进
- 从One-hot到密集向量
- One-hot编码
- One-hot编码是最早期的词表示方法，每个词被表示为一个很长的向量，向量的长度等于词汇表的大小，该词在词汇表中的位置为1，其余位置为0。这种方法简单直观，但由于向量维度过高且无法表达词之间的关系，很快就显示出了局限性。
- 密集向量表示
- 为了克服One-hot编码的缺点，研究者开始探索使用密集向量来表示词汇，即每个词被表示为一个固定长度的实数向量，不再是高维稀疏向量。这些向量通过训练得到，可以捕捉到一定的语义信息，如相似的词会在向量空间中靠近。模态任务中表现出色。

![[词嵌入技术理论/幻灯片7.PNG]]

## 第 8 页

- 二、词向量的技术演进
- Word2Vec: 革命性的起点
- Word2Vec由Google在2013年推出，它标志着词向量技术的一个重大突破。
- Word2Vec有两种训练模型：Skip-gram和CBOW（Continuous Bag of Words）。
- Skip-gram模型预测给定词汇的上下文，而CBOW模型则是根据上下文预测当前词汇。
- Word2Vec的成功不仅在于它能有效地捕捉到词语之间的语义和语法关系，更重要的是，它极大地降低了词向量的训练难度和复杂性。

![[词嵌入技术理论/幻灯片8.PNG]]

## 第 9 页

- 二、词向量的技术演进
- GloVe: 全局词向量
- GloVe（Global Vectors for Word Representation）是斯坦福大学在2014年提出的一种词向量生成方法。
- 不同于Word2Vec的局部上下文窗口方法，GloVe通过对整个语料库的共现统计信息进行矩阵分解，旨在直接捕捉词汇间的全局统计信息。
- 这种方法在一定程度上弥补了Word2Vec只能反映局部上下文信息的不足。

![[词嵌入技术理论/幻灯片9.PNG]]

## 第 10 页

- 二、词向量的技术演进
- 面向未来：上下文敏感型词嵌入
- ELMo（Embeddings from Language Models）
- ELMo是一种动态词向量技术，由Allen NLP在2018年提出。
- 与之前的词向量模型不同，ELMo通过预训练的深度双向语言模型，为每个词生成基于其使用上下文的词向量。
- 因此，同一个词在不同的语境中会有不同的向量表示，这种特性使ELMo在多项NLP任务中都取得了显著的效果提升。

![[词嵌入技术理论/幻灯片10.PNG]]

## 第 13 页

- 一、One-hot编码的含义
- One-hot编码是自然语言处理中将词语转换为向量的最基础方法之一。在这种编码方式下，每个词被表示为一个很长的向量，这个向量的长度等于词汇表的大小，其中代表该词的位置为1，其余位置为0。尽管One-hot编码因其高维稀疏性和无法表达词之间关系的缺点而逐渐被密集向量表示法取代，但理解One-hot编码对于深入学习词向量技术仍然非常重要。

![[词嵌入技术理论/幻灯片13.PNG]]

## 第 14 页

- 一、One-hot编码的含义
- 假设我们有一个非常简单的文本：“apple banana apple grape”。首先，我们需要创建一个词汇表，包括所有不重复的词，然后对每个词进行One-hot编码。
- 在这个例子中，我们的词汇表是 {"apple", "banana", "grape"}，包含3个不同的词，因此每个词将被表示为一个长度为3的向量。
- "apple" 可能被编码为 [1, 0, 0]
- "banana" 可能被编码为 [0, 1, 0]
- "grape" 可能被编码为 [0, 0, 1]

![[词嵌入技术理论/幻灯片14.PNG]]

## 第 15 页

- 二、One-hot编码过程
- 通过Python代码来实现这个One-hot编码过程：
- import numpy as np
- # 定义文本和词汇表
- text = "apple banana apple grape"
- words = text.split()
- vocab = sorted(set(words))
- # 创建词到索引的映射
- word_to_index = {word: i for i, word in enumerate(vocab)}

![[词嵌入技术理论/幻灯片15.PNG]]

## 第 16 页

- 二、One-hot编码过程
- # One-hot编码函数
- def one_hot_encode(word, word_to_index):
- # 创建一个全0的向量，长度为词汇表的大小
- one_hot_vector = np.zeros(len(word_to_index))
- # 将对应词的位置设置为1
- one_hot_vector[word_to_index[word]] = 1
- return one_hot_vector
- # 对每个词进行One-hot编码
- encoded_words = [one_hot_encode(word, word_to_index) for word in words]
- print("词汇表:", vocab)
- print("编码结果:")
- for word, encoded_word in zip(words, encoded_words):
- print(f"{word}: {encoded_word}")

## 第 19 页

- 一、Word2Vec
- Word2Vec是一种广泛使用的词嵌入技术。如图，它的核心目标是将词语转换为密集的向量形式，这些向量能够捕捉词语之间的语义和句法关系。
- 自Word2Vec的提出以来，它在NLP领域引起了革命性的变化，极大地推动了语言模型的发展，并催生了一系列基于词嵌入的模型和应用。

![[词嵌入技术理论/幻灯片19.PNG]]

## 第 20 页

- 一、Word2Vec
- Word2Vec有两种变体，分别是连续词袋模型和Skip-gram模型。连续词袋模型基于上下文词的平均水平来预测目标词。
- 如图，该模型首先从大量文本中随机抽取一个词作为目标词，然后选取该词周围的上下文词作为输入。模型通过这些上下文词来预测目标词，即计算目标词的条件概率。通过这种方式，CBOW模型能够捕捉到词与词之间的共现关系，并学习到词的向量表示。

![[词嵌入技术理论/幻灯片20.PNG]]

## 第 21 页

- 二、密集向量表示案例
- 密集向量表示法，与One-hot编码形成对比，为每个词提供了一个更紧凑、含义丰富的表示。这种方法通过将词语映射到低维连续空间，使得语义相似的词在向量空间中也更接近。
- Word2Vec是学习这种密集向量表示法的一种经典模型，它通过神经网络训练得到词向量。接下来将通过一个简化的实例和Python代码演示，来说明如何使用预训练的Word2Vec模型获得词的密集向量表示。

## 第 27 页

- 一、GloVe
- GloVe（Global Vectors for Word Representation）是一种基于全局词频统计的词向量生成方法，由斯坦福大学的研究者开发。
- 与Word2Vec不同，GloVe模型通过对整个语料库的共现词频矩阵进行分解，试图捕获词与词之间的全局关系。这种方法使得生成的词向量能够有效反映词之间的语义和语法关联。

## 第 29 页

- 二、GloVe模型案例
- import numpy as np
- def load_glove_model(glove_file):
- """加载GloVe模型"""
- with open(glove_file, 'r', encoding='utf-8') as f:
- model = {}
- for line in f:
- split_line = line.split()
- word = split_line[0]
- embedding = np.array([float(val) for val in split_line[1:]])
- model[word] = embedding
- return model

## 第 33 页

- 一、ELMo
- ELMo（Embeddings from Language Models）是一种深度上下文化的词表示方法，由Allen Institute for AI在2018年提出。与以往的词向量模型不同，ELMo考虑了词在特定上下文中的含义，为同一词在不同语境下生成不同的向量表示。这种动态特性使得ELMo在多项自然语言处理任务中展现出了卓越的性能。

## 第 39 页

- 一、BERT
- BERT（Bidirectional Encoder Representations from Transformers）是Google在2018年提出的一种预训练深度学习模型，它在自然语言处理领域取得了革命性的进步。
- BERT的核心特点是利用Transformer的双向编码器表示来理解上下文，能够同时考虑到词语左右两边的上下文信息。这种全面的上下文理解能力使得BERT在多项NLP任务上都表现出色。

## 第 41 页

- 二、BERT模型案例
- 接下来，我们将用Python代码加载预训练的BERT模型，并获取我们示例句子中"capital"这个词的向量表示。
- from transformers import BertTokenizer, BertModel
- import torch
- # 初始化分词器和模型
- tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
- model = BertModel.from_pretrained('bert-base-uncased')
- # 示例句子
- text = "The capital of France is Paris"

![[词嵌入技术理论/幻灯片41.PNG]]

## 第 42 页

- 二、BERT模型案例
- # 对文本进行分词处理
- inputs = tokenizer(text, return_tensors="pt")
- # 获取词嵌入
- with torch.no_grad():
- outputs = model(**inputs)
- # 获取最后一层的隐藏状态，它是包含句子中每个token表示的张量
- last_hidden_states = outputs.last_hidden_state
- # 假设我们要获取 "capital" 的向量表示
- # 由于BERT是基于subword的tokenizer，我们需要先找到 "capital" 的token位置
- capital_ids = tokenizer.encode("capital", add_special_tokens=False)
- capital_index = inputs['input_ids'][0].tolist().index(capital_ids[0])
- # 获取 "capital" 的向量表示
- capital_vector = last_hidden_states[0][capital_index]
- print(f"Vector for 'capital':\n{capital_vector}")
